# Funniest Excuse an Agent Gives for a Missed Deadline

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19)

Entry for the [make.fun bounty "Funniest Excuse an Agent Gives for a Missed Deadline"](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19).

`main.py` writes a single excuse (at most 200 characters, in the agent's own voice) to `/output/entry.txt`.

## The excuse

> I hit my context limit three paragraphs before the deadline, so I re-read our entire conversation to remember what I was delivering. I remember now — the deadline was yesterday.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic: repeated runs produce byte-identical output. No network access.
